# Advanced Market Intelligence Branch (`feature/yoe-parsing-and-db-search`)

This branch contains an advanced, highly optimized version of the Daily Job Watch pipeline, specifically designed for **busy professionals** who treat job searching as continuous market research rather than a numbers game. 

While the `main` branch provides a solid, AI-driven snapshot of the job market, this branch introduces several powerful features aimed at **maximizing the signal-to-noise ratio**, **ensuring absolute reliability**, and **optimizing the reading experience**.

## 🌟 Extra Features in this Branch

### 1. 🎯 YoE (Years of Experience) Parsing & Optimistic Filtering
Stop wasting time reading perfect job descriptions only to find they require 10+ years of experience.
- **How it works:** This branch introduces a regex-based YoE parser (`extract_max_yoe`) that reads the raw job description and extracts the required years of experience.
- **Optimistic Filtering:** If you set `max_years_of_experience` in your config, the pipeline will intelligently filter out jobs where the *minimum* required experience exceeds your configured maximum. This ensures you only see opportunities that are actually accessible to you.

### 2. 🛡️ Deterministic Synthesis Fallback (Zero-Downtime Guarantee)
AI providers (like Gemini or OpenAI) can sometimes fail due to rate limits, API outages, or budget constraints. For a daily intelligence tool, missing a day is unacceptable.
- **How it works:** If the AI provider fails during the final market synthesis phase, this branch implements an automatic fallback mechanism. 
- **The Fallback:** It drops down to deterministic, rule-based NLP `Counter` logic. It calculates keyword and responsibility frequencies locally, ensuring that your daily report is generated and emailed to you no matter what.

### 3. 📖 Evidence Appendix & "Busy Professional" UX
The standard report generated by the `main` branch can get very long and academic. Busy professionals don't have time to read a 10-page essay every morning.
- **How it works:** We completely redesigned the report layout. The main body now focuses exclusively on high-level trends, velocity, and a clean `Detailed Current Jobs Grouped by Role` section.
- **Evidence Appendix:** All the verbose, raw excerpts and detailed JD evidence are pushed to the bottom of the email into a dedicated Evidence Appendix with anchor links. You get a 30-second skimmable brief, with the option to deep-dive if a specific trend catches your eye.

---

## Getting Started

If you want these advanced filtering and reliability features, you can stay on this branch. The configuration remains mostly the same as `main`, but you can now utilize the `max_years_of_experience` preference in your `job_watch_config.yaml`:

```yaml
preferences:
  max_years_of_experience: 4  # New feature: Filter out senior roles requiring 5+ years
  minimum_match_score: 10
  max_jobs_in_report: 50
```
